# 🎧 پک صداگذاری محتوا — یوتیوب و اینستاگرام

**مخصوص محتوای تکنولوژی و آموزشی** · ۳۱ افکت صوتی + ۸ ترک موسیقی پس‌زمینه + راهنمای کامل «کجا استفاده کنم»

> ⚡ همه‌ی فایل‌های صوتی با **سنتز کد** ساخته شده‌اند (نه دانلود از کتابخانه‌های آماده).
> یعنی **۱۰۰٪ اورجینال، بدون کپی‌رایت، بدون Content ID، بدون نیاز به ذکر منبع، و قابل استفاده‌ی تجاری.**

---

## 📂 ساختار پوشه‌ها

```
audio-pack/
├── sfx/            ← ۳۱ افکت صوتی — WAV (استریو ۴۴.۱kHz، کیفیت اصلی)
├── bgm/            ← ۸ ترک موسیقی — WAV
├── mp3/
│   ├── sfx/        ← همان افکت‌ها به MP3 (برای موبایل و CapCut)
│   └── bgm/        ← همان موزیک‌ها به MP3 (۱۹۲kbps)
└── measured.csv    ← مدت‌زمان و بلندی اندازه‌گیری‌شده‌ی هر فایل

guides/
├── guide.html      ← 🌟 راهنمای بصری کامل (این را باز کن)
├── README.md       ← راهنمای کامل متنی
└── audio-library.xlsx ← جدول فیلترشدنی: افکت‌ها، موزیک‌ها، منابع، تایم‌لاین، چک‌لیست

sfx-lab/            ← کد سازنده‌ی همه‌ی فایل‌ها (قابل شخصی‌سازی)
```

---

## 🚀 در ۳۰ ثانیه

1. **`guides/guide.html`** را باز کن → جدول کامل «هر افکت دقیقاً کجا استفاده شود» آنجاست.
2. فایل‌های صوتی را از `audio-pack/sfx` (یا `mp3`) به ادیتورت ببر.
3. این سه ترک را همین امروز استفاده کن:
   - **`room_tone_loop`** → زیر کل ویدیو، روی **−۳۲ dB**، لوپ. (سکوت مطلق را از بین می‌برد)
   - **`bgm_tech_explainer`** → موزیک اصلی، روی **−۲۰ dB** زیر صدای خودت.
   - **`impact_deep`** → روی فریمی که عدد/نتیجه‌ی مهم ظاهر می‌شود، **−۸ dB**.

## 🛠️ شخصی‌سازی

```bash
cd sfx-lab
OUTDIR=../audio-pack/sfx  python3 build_sfx_extra.py   # ساخت هر ۳۱ افکت
OUTDIR=../audio-pack/bgm  python3 build_bgm.py         # ساخت هر ۸ ترک
PACKDIR=../audio-pack     python3 encode_mp3.py        # MP3 + نرمالایز + گزارش LUFS
```

پارامترهای کلیدی: `peak` (بلندی) · `bpm` · `prog` (توالی آکورد) · `master_lp` (تیره‌کردن موزیک زیر ویس → ۴۵۰۰)
