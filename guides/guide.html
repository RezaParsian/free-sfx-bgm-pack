🎚️ سه قدم راه‌اندازی

۱) افکت‌ها را روی یک ترک صوتی جدا زیر صدای خودت بگذار.
۲) موزیک را روی ترک دیگر و −۲۰ dB زیر ویس.
۳) room_tone_loop را از ابتدا تا انتها لوپ کن.

خبر خوب: همه‌ی فایل‌ها از قبل نرمالایز شده‌اند (افکت‌ها −۱۸ LUFS، موزیک‌ها −۲۰ LUFS). یعنی اگر بدون تغییر سطح روی تایم‌لاین بگذاری، نسبت افکت‌ها به هم از قبل درست است — فقط کل ترک موزیک را پایین بده تا زیر حرفت گم شود.

Ducking (کم‌شدن خودکار موزیک زیر حرف)

CapCut: ترک موزیک → Audio → Ducking را روشن کن.
Premiere: Essential Sound → موزیک را Music و ویس را Dialogue علامت بزن → Ducking → Generate Keyframes. تنظیم پیشنهادی: Duck Amount = −۱۸ dB، Ramp = 300ms.
DaVinci Resolve: تب Fairlight → Music Ducking (یا Sidechain روی کمپرسور ترک موزیک).

دستی: هر جا حرف می‌زنی موزیک −۲۰ dB، هر جا ساکتی −۱۲ dB، با رمپ ۲۵۰ تا ۳۵۰ میلی‌ثانیه.

اندازه‌گیری بلندی خروجی

ffmpeg -i video.mp4 -af ebur128=peak=true -f null -

در خروجی، I: = بلندی یکپارچه (باید حدود −۱۴ باشد) و Peak: نباید از −۱ dBTP بالاتر برود.

۰۷قوانین طلایی — چک‌لیست قبل از اکسپورت

  • در هر ۱۰ ثانیه بیشتر از ۲ افکت نگذار (مگر ریلز تند).
  • از یک افکت بیش از ۵ بار در دقیقه استفاده نکن؛ گوش عادت می‌کند و اثرش صفر می‌شود.
  • افکت UI باید دقیقاً روی فریم رخداد باشد — ۲ فریم خطا یعنی «غیرحرفه‌ای».
  • اگر ویس و موزیک تضاد دارند، موزیک را کم کن؛ ویس را تقویت نکن.
  • قبل از نکته‌ی مهم: ۰.۵ ثانیه سکوت + impact_deep → قوی‌تر از هر افکت پرصدا.
  • هیچ‌وقت سکوت دیجیتال مطلق نگذار؛ room_tone زیر همه‌چیز باشد.
  • بیسِ boom روی اسپیکر گوشی شنیده نمی‌شود → یک لایه impact_bright هم رویش بگذار.
  • خروجی: −۱۴ LUFS و True Peak زیر −۱ dB.
  • سه بار مرور کن: بار اول تصویر، بار دوم با چشم بسته فقط صدا، بار سوم با گوشی.
  • لایسنس هر فایل خارجی را بخوان و رسید/اسکرین‌شاتش را نگه دار.

۰۸کپی‌رایت و امنیت کانال

این پک: صفر ریسک. همه‌چیز از صفر سنتز شده و هیچ نمونه‌ی صوتیِ کسی در آن نیست — نه Content ID، نه Claim، نه Strike. حتی می‌توانی logo_sting را به امضای صوتی برندت تبدیل کنی.

  2. CC0 = کاملاً آزاد · CC BY = آزاد با ذکر منبع در توضیحات · CC BY-NC = برای ویدیوی درآمدزا ممنوع.
  3. اگر سایتی «Credit» خواست، متن را دقیقاً کپی کن و در Description یوتیوب بگذار.
  4. رسید یا اسکرین‌شات لایسنس هر ترک را ذخیره کن — اگر روزی Claim بیاید، تنها مدرکت همین است.
  5. به کانال‌های «No Copyright Music» یوتیوب اعتماد کامل نکن؛ خیلی‌ها بعداً لایسنس را عوض می‌کنند و روی ویدیوهای قدیمی‌ات Claim می‌زنند.

۰۹ساخت فایل جدید / شخصی‌سازی

کد سازنده‌ی همه‌ی فایل‌ها در پوشه‌ی sfx-lab/ هست و قابل تغییر است.

cd sfx-lab OUTDIR=../audio-pack/sfx python3 build_sfx_extra.py # ساخت هر ۳۱ افکت OUTDIR=../audio-pack/bgm python3 build_bgm.py # ساخت هر ۸ ترک موسیقی PACKDIR=../audio-pack python3 encode_mp3.py # تبدیل MP3 + نرمالایز + گزارش LUFS

چه چیزی را کجا عوض کنی

build_sfx.py → تابع هر افکت: peak بلندی، d طول، width پهنای استریو، pan مکان چپ/راست
build_bgm.py → bpm، bars تعداد میزان، prog توالی آکوردها، master_lp فرکانس قطع
audio_engine.py → سازها و فیلترها (karplus، bell، pad، reverb، sidechain)
