# 🎧 پک افکت صوتی + موسیقی پس‌زمینه — مخصوص محتوای تکنولوژی و آموزشی

> همه‌ی فایل‌های صوتی این پک **از صفر با کد سنتز شده‌اند** (نه دانلود از کتابخانه‌های آماده).
> یعنی: **۱۰۰٪ اورجینال، بدون کپی‌رایت، بدون Content ID، قابل استفاده‌ی تجاری و بدون نیاز به ذکر منبع.**
> حتی می‌توانی بفروشی‌شان یا به‌عنوان لوگوی صوتی برندت ثبت کنی.

---

## ۱) چه چیزی داری؟

| پوشه | محتوا | تعداد | حجم |
|---|---|---|---|
| `audio-pack/sfx/` | افکت‌ها — نسخه‌ی WAV (استریو، ۴۴.۱kHz، بدون افت کیفیت) | ۳۱ | ~۱۳MB |
| `audio-pack/bgm/` | موسیقی پس‌زمینه — نسخه‌ی WAV | ۸ | ~۴۳MB |
| `audio-pack/mp3/sfx/` | همان افکت‌ها به‌صورت MP3 (برای موبایل/ادیت سریع) | ۳۱ | ~۲MB |
| `audio-pack/mp3/bgm/` | همان موزیک‌ها به‌صورت MP3 (۱۹۲kbps، نرمالایز شده روی −۲۰ LUFS) | ۸ | ~۵MB |
| `audio-pack/measured.csv` | مدت‌زمان و بلندی اندازه‌گیری‌شده‌ی هر فایل | — | — |

**کدام را استفاده کنم؟**
- **ادیت در پریمیر/داوینچی/فاینال‌کات/Adobe Audition** → `WAV` (کیفیت اصلی، برای تغییر سرعت و کش‌دان بدون افت)
- **ادیت در CapCut / InShot / موبایل / ارسال برای دیگران** → `MP3`
- **کپ‌کات دسکتاپ و وب** هم WAV را قبول می‌کند؛ اگر پروژه‌ات سنگین شد MP3 بردار.

## ۲) شروع سریع (۳ قدم)

1. کل پوشه‌ی `audio-pack` را به کامپیوتر/گوشی منتقل کن.
2. در تایم‌لاین ادیت، فایل‌ها را بکش روی **یک ترک صوتی جدا** (ترک SFX) زیر صدای خودت.
3. سطح‌ها را طبق جدول بخش ۶ تنظیم کن: **صدا (ویس) همیشه پادشاه است**؛ موزیک و افکت فقط پشتیبان‌اند.

> ⚠️ رایج‌ترین اشتباه تازه‌کارها: افکت را روی همان بلندیِ فایل خام رها می‌کند. همه‌ی فایل‌های این پک روی **−۱۸ LUFS** (افکت) و **−۲۰ LUFS** (موزیک) نرمالایز شده‌اند، یعنی اگر بدون تغییر سطح روی تایم‌لاین بگذاری، **نسبت‌ها از قبل درست است** — فقط کل ترک موزیک را ۸ تا ۱۲ دسی‌بل پایین بده تا زیر حرفت گم شود.

## ۳) جدول افکت‌ها + دقیقاً کجا استفاده کنی

علامت سطح: مقدار پیشنهادی relative gain در ادیتور (نسبت به صدای اصلی خودت).

### ۳-۱) ترنزیشن و کات (پرکاربردترین گروه)

| فایل | کجا استفاده شود | سطح | نکته‌ی حرفه‌ای |
|---|---|---|---|
| `whoosh_transition` | روی هر کات بزرگ: تغییر بخش، زوم‌این روی محصول، ورود به اسکرین‌رکوردر | −۸ تا −۶ dB | شروع افکت را **۳ تا ۵ فریم قبل از کات** بگذار، نه دقیقاً روی کات → طبیعی‌تر می‌شود |
| `whoosh_short` | جامپ‌کات‌های سریع داخل حرف‌زدن (حذف تپق‌ها) | −۱۲ تا −۱۰ dB | در ویدیوی ۱۰ دقیقه‌ای بیشتر از ۲۰ بار استفاده نکن؛ وگرنه «شلوغ» می‌شود |

### ۴-۲) نقشه‌ی موزیک در یک ویدیوی بررسی محصول (۸ دقیقه‌ای)

```
0:00 ─ 0:03   هوک             → bgm_hook_loop_8s  (بلند: −۱۴ dB) + impact_deep روی فریم آخر
0:03 ─ 0:12   اینترو/لوگو     → logo_sting        (بدون موزیک، فقط استینگ)
0:12 ─ 2:30   معرفی محصول     → bgm_tech_explainer (−۲۰ dB)  — ریتم متوسط
2:30 ─ 4:00   مشخصات/اسلاید   → bgm_screen_bed     (−۲۴ dB)  — کاملاً خلوت، زیر توضیح
4:00 ─ 5:00   بنچمارک/تست     → bgm_cinematic_tension (−۲۰ dB) + riser قبل از نتیجه
5:00 ─ 6:30   نکات و ترفندها  → bgm_playful_marimba (−۲۲ dB)
6:30 ─ 7:30   جمع‌بندی        → bgm_tech_explainer (−۲۰ dB)  — بازگشت به تم اصلی
7:30 ─ 8:00   CTA/سابسکرایب   → logo_sting + success_chime
کل ویدیو      ترک زیرین       → room_tone_loop     (−۳۲ dB)
```

> 🔑 **قانون تغییر موزیک:** موزیک را فقط در مرز «بخش‌ها» عوض کن، نه وسط جمله. و همیشه یک **Crossfade نیم‌ثانیه‌ای** بین دو ترک بگذار، وگرنه برش ناگهانی گوش را می‌زند.

|---|---|
| 0.0–0.5 | **ضربه‌ی اول**: `impact_deep` یا `boom_cinematic` — بدون استثنا. ۷۰٪ ری‌تنشن همین‌جا تعیین می‌شود |
| 0.5–3 | `bgm_hook_loop_8s` روی لوپ + هر کات با `cut_tick` |
| هر متن روی تصویر | `text_reveal_soft` یا `pop_bubble` |
| لحظه‌ی «واو» | `sparkle_magic` یا `success_chime` |
| شوخی/میم | `air_horn_meme` یا `laser_pew` |
| پایان/CTA | `vinyl_stop` + `logo_sting` کوتاه |

> ⚠️ **تفاوت مهم ریلز و یوتیوب:** در ریلز صدای **Trending Audio** اینستاگرام الگوریتمی کمک می‌کند. پس استراتژی درست این است: موزیک ترند را روی حجم **خیلی کم** (−۲۴ dB) زیر کار بگذار و افکت‌های خودت را رویش بچین. در یوتیوب برعکس: موزیک باید کاملاً بی‌کپی‌رایت باشد.

## ۶) تنظیم سطح صدا (Gain Staging) — مهم‌ترین بخش فنی

### اعداد هدف

| عنصر | سطح پیشنهادی روی تایم‌لاین | بلندی نهایی خروجی |
|---|---|---|
| صدای خودت (Voice-over) | 0 dB (مرجع) | −۱۶ تا −۱۴ LUFS |
| موسیقی پس‌زمینه | **−۲۰ تا −۱۶ dB** زیر ویس | — |
| موسیقی در اینترو/اوترو (بدون ویس) | −۱۴ تا −۱۲ dB | — |
| افکت‌های تاکید (impact/boom) | −۸ تا −۶ dB | — |
| افکت‌های ترنزیشن (whoosh/riser) | −۱۰ تا −۸ dB | — |
| افکت‌های UI (click/pop/tick) | −۱۴ تا −۱۰ dB | — |
| Ambience (room tone/crackle) | −۳۴ تا −۲۸ dB | — |

### استانداردهای پلتفرم

| پلتفرم | بلندی هدف | True Peak |
|---|---|---|
| YouTube | **−۱۴ LUFS** | حداکثر **−۱ dBTP** |
| Instagram / Reels | −۱۴ LUFS | −۱ dBTP |
| پادکست (Spotify/Apple) | −۱۶ تا −۱۴ LUFS | −۱ dBTP |

اگر خروجی‌ات بلندتر از −۱۴ LUFS باشد، یوتیوب **خودش صدایش را کم می‌کند** (نرمالایز می‌کند) و داینامیک کارت له می‌شود. اگر quieter باشد، بیننده مجبور است ولوم را بالا ببرد → خارج می‌شود.

### Ducking (کم‌کردن خودکار موزیک زیر حرف)

در **CapCut**: روی ترک موزیک → `Audio` → `Ducking` را روشن کن.
در **Premiere**: `Essential Sound` → موزیک را `Music` و ویس را `Dialogue` علامت بزن → `Ducking` → `Generate Keyframes`. تنظیم پیشنهادی: `Duck against: Dialogue`، `Sensitivity: High`، `Duck Amount: −۱۸ dB`، `Ramp: 300ms`.
در **DaVinci Resolve**: ترک ویس را انتخاب کن → `Fairlight` → `Music Ducking` (یا `Sidechain` روی کمپرسور ترک موزیک).

اگر دستی انجام می‌دهی: هر جا حرف می‌زنی موزیک −۲۰ dB، هر جا ساکتی −۱۲ dB، با رمپ ۲۵۰ تا ۳۵۰ میلی‌ثانیه.

### اندازه‌گیری بلندی (اختیاری ولی حرفه‌ای)

```bash
ffmpeg -i video.mp4 -af ebur128=peak=true -f null -
```
در خروجی، `I:` یعنی بلندی یکپارچه (باید حدود −۱۴ باشد) و `Peak:` نباید از −۱ dBTP بالاتر برود.

## ۷) قوانین طلایی (چک‌لیست قبل از اکسپورت)

- [ ] **قانون ۱۰ ثانیه:** در هر ۱۰ ثانیه بیشتر از ۲ افکت نگذار (مگر در ریلز تند).
- [ ] **تنوع:** از یک افکت واحد بیشتر از ۵ بار در دقیقه استفاده نکن → گوش عادت می‌کند و اثرش صفر می‌شود.
- [ ] **هم‌زمانی فریمی:** افکت UI باید دقیقاً روی فریم رخداد باشد. ۲ فریم جابه‌جایی = حس «غیرحرفه‌ای».
- [ ] **ویس همیشه اول:** اگر بین موزیک و صدای خودت تضاد هست، موزیک را کم کن. هرگز ویس را تقویت نکن تا به موزیک برسد.
- [ ] **سکوت هم ابزار است:** قبل از یک نکته‌ی مهم، ۰.۵ ثانیه سکوت + یک `impact_deep` → اثرش از هر افکت پرصدا بیشتر است.
- [ ] **room tone زیر همه‌چیز:** هیچ‌وقت سکوت دیجیتال مطلق نگذار.
- [ ] **مانیتور با هدفون + اسپیکر گوشی:** ۸۰٪ مخاطب اینستاگرام با گوشی و بدون هدفون می‌بیند. بیسِ `boom_cinematic` روی اسپیکر گوشی شنیده نمی‌شود → برای موبایل لایه‌ی فرکانس بالا (`impact_bright`) اضافه کن.
- [ ] **خروجی روی −۱۴ LUFS** و True Peak زیر −۱ dB.
- [ ] **۳ بار پشت سر هم ببین:** بار اول برای تصویر، بار دوم با چشم بسته فقط برای صدا، بار سوم با گوشی.

## ۸) کپی‌رایت و امنیت کانال

**این پک:** هیچ ریسکی ندارد — همه چیز سنتز شده و هیچ نمونه‌ی صوتیِ کسی در آن نیست. نه Content ID، نه Claim، نه Strike.

**برای منابع خارجی، این ۵ قانون را رعایت کن:**
1. قبل از دانلود، **لایسنس همان فایل** را بخوان (نه لایسنس کلی سایت).
2. `CC0` = کاملاً آزاد. `CC BY` = آزاد با ذکر منبع در توضیحات. `CC BY-NC` = **برای ویدیوی درآمدزا ممنوع**.
3. اگر سایتی «Credit» خواست، متن را **دقیقاً** کپی کن و در Description یوتیوب بگذار.
4. رسید/لایسنس هر ترک خریداری‌شده را **ذخیره کن** (PDF یا اسکرین‌شات). اگر روزی Claim بیاید، تنها مدرکت همین است.
5. به «No Copyright Music» در یوتیوب اعتماد کامل نکن — خیلی از این کانال‌ها بعداً لایسنس را عوض می‌کنند و روی ویدیوهای قدیمی‌ات Claim می‌زنند. منبع رسمی (YouTube Audio Library / Pixabay) امن‌تر است.

## ۹) ساخت فایل‌های جدید

اگر خواستی افکت را تغییر دهی (مثلاً کوتاه‌تر، زیرتر، یا با پیچ متفاوت)، کدش در `sfx-lab/` هست:

```bash
cd sfx-lab
OUTDIR=../audio-pack/sfx python3 build_sfx_extra.py     # ساخت همه‌ی ۳۱ افکت
OUTDIR=../audio-pack/bgm python3 build_bgm.py          # ساخت هر ۸ موزیک
PACKDIR=../audio-pack python3 encode_mp3.py            # تبدیل به MP3 + نرمالایز + گزارش LUFS
```

پارامترهای قابل تغییر:
- **`build_sfx.py`** → تابع هر افکت؛ `peak=` بلندی، `dur`/`d=` طول، `width=` پهنای استریو، `pan=` مکان چپ/راست
- **`build_bgm.py`** → `bpm=`، `bars=` تعداد میزان، `prog=` توالی آکوردها، `master_lp=` فرکانس قطع (برای تیره‌تر کردن موزیک زیر ویس)
- **`audio_engine.py`** → سازها و فیلترها (karplus، bell، pad، reverb، sidechain)

> 💡 سریع‌ترین راه برای موزیک زیر ویس: `master_lp` را روی ۴۵۰۰ بگذار → موزیک «تیره» می‌شود و جای فرکانس صدای انسان (۱ تا ۴ kHz) خالی می‌ماند.
